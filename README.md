# birds

Предварительно убедиться, что установлен python3.10 или 3.12
1. Скачать PyCharm
2. Создать новый проект и туда добавить birds_analytics.py
3. Создать и активировать виртуальное окружение в папке проекта
  3.1 в terminal-е (внутри pyCharm) написать "python -m venv bird_env"
  3.2 там же в terminal-е написать "source bird_env/bin/activate"
4. также в terminal-е установить библиотеку pymorphy3 командой "pip3 install nltk pymorphy3"
   если не получится через терминал, то можно в самом скрипте правой кнопкой мыши кликнуть на pymorphy3 на третьей строчке скрипта и нажать "Show Context Actions" и "установить pymorphy3"
5. запустить скрипт зеленой кнопкой, в консоли будет ответ
